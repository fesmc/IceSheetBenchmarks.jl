# IceSheetBenchmarks.jl

Portable, model-agnostic Julia package providing the standard
ice-sheet benchmark specifications: grid geometry, forcing fields,
and (where they exist) analytical or empirical reference solutions.
Each benchmark is returned as a plain Julia struct and as a NamedTuple
of fields keyed by ice-sheet schema names, so any ice-sheet model
implementation can consume them.

## Installation

```julia
pkg> add https://github.com/fesmc/IceSheetBenchmarks.jl
```

## At a glance

```julia
using IceSheetBenchmarks

# Halfar dome (Bueler-B) on a 25 km grid:
b = BuelerBenchmark(:B; dx_km = 25.0)
s = state(b, 0.0)
# s.H_ice, s.z_bed, s.smb_ref, s.xc, s.yc

# Closed-form depth-averaged velocity at t = 100 yr:
ux_bar, uy_bar = analytical_velocity(b, 100.0)

# Serialise to a NetCDF restart fixture:
write_fixture!(b, "bueler_B.nc"; times = [0.0])
```

## Included benchmarks

| Benchmark                       | Reference                            | Analytical state | Analytical velocity |
| ------------------------------- | ------------------------------------ | :--------------: | :-----------------: |
| [`BuelerBenchmark(:B / :C)`](benchmarks/bueler.md)      | Bueler et al. 2005 — Halfar dome     | yes              | yes                 |
| [`HOMCBenchmark(:C)`](benchmarks/hom_c.md)             | Pattyn et al. 2008 — ISMIP-HOM Exp C | IC only          | no                  |
| [`TroughBenchmark(:F17)`](benchmarks/trough.md)         | Feldmann & Levermann 2017            | host-provided    | no                  |
| [`EISMINT1MovingBenchmark`](benchmarks/eismint_moving.md)       | Huybrechts et al. 1996               | IC only          | no                  |
| [`MISMIP3DBenchmark(:Stnd)`](benchmarks/mismip3d.md)      | Pattyn et al. 2013                   | IC only          | no                  |
| [`CalvingMIPBenchmark(:exp1..:exp4)`](benchmarks/calvingmip.md) | Cornford et al. (CalvingMIP)         | IC only          | no                  |
| [`InitMIPBenchmark`](benchmarks/initmip.md)              | Goelzer et al. 2018 — InitMIP        | stub             | no                  |

For non-analytical benchmarks the host model is expected to provide
`state(b, t > 0)` (e.g. by reading a host-produced reference fixture)
and `write_fixture!(b, …)` (e.g. by driving the host's own model).

## Design

- **Minimal dependencies.** Only [`NCDatasets`](https://github.com/JuliaGeo/NCDatasets.jl)
  in the core package.
- **Plain-text and NetCDF assets.** Fixtures and reference fields are
  serialised to NetCDF; configuration is plain Julia code.
- **Uniform interface.** Every benchmark implements the same three
  entry points (see [Interface](interface.md)).
- **Host extensions.** Model-specific glue (Field types, halo
  conventions, mesh objects) lives in package extensions, not in the
  core spec.
