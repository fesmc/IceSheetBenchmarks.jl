IceSheetBenchmarks.jl

Portable, model-agnostic Julia package providing the standard ice-sheet benchmark specifications: grid geometry, forcing fields, and (where they exist) analytical or empirical reference solutions. Each benchmark is returned as a plain Julia struct and as a NamedTuple of fields keyed by ice-sheet schema names, so any ice-sheet model implementation can consume them.

Installation

pkg> add https://github.com/fesmc/IceSheetBenchmarks.jl

At a glance

using IceSheetBenchmarks

# Halfar dome (Bueler-B) on a 25 km grid:
b = BuelerBenchmark(:B; dx_km = 25.0)
s = state(b, 0.0)
# s.H_ice, s.z_bed, s.smb_ref, s.xc, s.yc

# Closed-form depth-averaged velocity at t = 100 yr:
ux_bar, uy_bar = analytical_velocity(b, 100.0)

# Serialise to a NetCDF restart fixture:
write_fixture!(b, "bueler_B.nc"; times = [0.0])

For non-analytical benchmarks the host model is expected to provide state(b, t > 0) (e.g. by reading a host-produced reference fixture) and write_fixture!(b, …) (e.g. by driving the host's own model).

Design

  • Minimal dependencies. Only NCDatasets in the core package.
  • Plain-text and NetCDF assets. Fixtures and reference fields are serialised to NetCDF; configuration is plain Julia code.
  • Uniform interface. Every benchmark implements the same three entry points (see Interface).
  • Host extensions. Model-specific glue (Field types, halo conventions, mesh objects) lives in package extensions, not in the core spec.
