API reference

All exported symbols, grouped by topic.

Interface

IceSheetBenchmarks.AbstractBenchmark — Type
AbstractBenchmark

Supertype of every benchmark spec in this package. Concrete subtypes carry the parameters of a benchmark (grid axes, forcing parameters, Glen-flow parameters, …) and implement the small interface documented under state, write_fixture!, and optionally analytical_velocity.

source
IceSheetBenchmarks.state — Function
state(b::AbstractBenchmark, t::Real) -> NamedTuple

Analytical state of benchmark b at time t (years). Returns a NamedTuple keyed by ice-sheet schema names — see the Interface page for the catalogue of keys. Benchmarks without a closed-form solution may restrict to t = 0 (initial condition) and error otherwise.

source
IceSheetBenchmarks.write_fixture! — Function
write_fixture!(b::AbstractBenchmark, path; times=[t]) -> Vector{String}

Serialise state(b, t) at one or more times to a NetCDF restart at path. Returns the vector of file paths written. Some benchmarks support only a single time.

source
IceSheetBenchmarks.analytical_velocity — Function
analytical_velocity(b::AbstractBenchmark, t::Real) -> (ux_bar, uy_bar)

Closed-form depth-averaged ice-velocity field. ux_bar is shape (Nx+1, Ny) and uy_bar is (Nx, Ny+1) (face-staggered). Only implemented for benchmarks with a known analytical solution (currently BuelerBenchmark). The fallback throws an informative error.

source

Calving-law hooks

IceSheetBenchmarks.calvmip_exp1! — Function
calvmip_exp1!(cr_x, cr_y, u_bar, v_bar, H_ice, f_ice, lsf, time;
              xc, yc, r_lim = 750e3)

In-place velocity-equilibrium calving-rate law for CalvingMIP Exp1/Exp3. Skeleton declared here so hosts (or the YelmoBenchmarks extension) can extend it. See the CalvingMIP page for the arguments and staggered shapes.
